# Default chart of accounts

A small, sensible starting chart for a service or software business. Add accounts
as the user needs them, and persist the working chart to memory (trove or NUMERA.md)
so it stays stable month to month.

## Assets
- Bank
- Accounts receivable (money owed to you)
- Prepayments
- Equipment / fixed assets
- VAT / sales-tax receivable

## Liabilities
- Accounts payable (money you owe)
- Credit card
- Loans
- VAT / sales-tax payable
- Accruals

## Equity
- Owner capital
- Retained earnings

## Income
- Sales
- Interest income

## Expenses
- Cost of sales
- Rent + facilities
- Hosting + software
- Marketing
- Travel
- Meals + entertainment
- Office supplies
- Bank charges
- Professional fees
- Payroll
- Depreciation

## Coding tips
- Recurring software/SaaS vendors -> **Hosting + software**.
- Ride-hail, flights, hotels -> **Travel**.
- Card processor / bank monthly fees -> **Bank charges**.
- Anything genuinely ambiguous -> ask the user once, then save the rule to memory so
  you never ask about that vendor again.
